# 高级 WebSocket Pro（修复版）

> 一个更稳定、更健壮的 WebSocket 扩展，专为 CCW / Gandi 联机游戏与实时通信场景打造。

## 🎯 设计目标（解决什么问题）
原版 `advancedWebSocket` 和基础改版 `MiaosAdvancedWebSocket` 在使用中存在一些痛点，本 Pro 版旨在彻底修复它们：
1. **断线重连丢失 URL**：原版重连时会导致连接回退到默认 `localhost`，现已被修正。
2. **后台无限重连**：修复了手动断开后仍偷偷“仰卧起坐”疯狂重连的 Bug。
3. **内存泄漏隐患**：补全了 `PROJECT_STOP_ALL` 事件监听，项目停止时自动清理资源。
4. **消息类型匹配与输出**：修复了类型不匹配，并优化了 `[object Object]` 的输出格式。
5. **CCW 沙箱适配**：新增 CCW 标准 Base64 内联 SVG 图标，免外部资源请求，完美适配沙箱。

## 🎮 核心功能
- **连接/断开**：支持任意 WebSocket 服务器地址。
- **多类型发送**：发送文本消息、JSON 消息、命令。
- **事件接收**：支持“当收到文本消息时”、“当收到命令时”、“当连接成功时”、“当连接断开时”等事件积木。
- **重连策略**：自定义最大重连次数与间隔。
- **状态报告**：提供“已连接?”、“最后收到的消息”、“消息类型”、“命令参数”等报告积木。

## 📨 服务端接收内容说明（JSON 消息结构）

扩展内部所有通信都基于 **JSON 字符串**。发送时由积木自动封装，接收时尝试解析为 JSON；若解析失败，则自动按纯文本处理。

### 1. 发送文本消息（`发送文本消息` 积木）
```json
{
  "type": "message",
  "data": "Hello Scratch!",
  "timestamp": 1758720000000
}
```
- `type`：消息类型，可在积木中自定义（默认 `message`）。
- `data`：字符串内容。
- `timestamp`：毫秒时间戳，由扩展自动生成。

### 2. 发送 JSON 消息（`发送JSON消息` 积木）
```json
{
  "type": "data",
  "data": { "key": "value" },
  "timestamp": 1758720000000
}
```
- `data` 字段可以是任意 JSON 对象或数组。
- 若在积木中输入非法 JSON，扩展会报错并忽略本次发送。

### 3. 发送命令（`发送命令` 积木）
```json
{
  "type": "command",
  "command": "move",
  "params": "forward",
  "timestamp": 1758720000000
}
```
- `type` 固定为 `"command"`。
- `command`：命令名称，可在积木中自定义（默认 `move`）。
- `params`：命令附带的参数，字符串类型。

### 4. 接收普通文本 / JSON 消息
当收到合法 JSON 且 `type` 不为 `"command"` 时，触发 `当收到 [TYPE] 文本消息时` 积木。

**示例收到的数据：**
```json
{
  "type": "move",
  "data": { "x": 5, "y": 7, "player": "A" },
  "timestamp": 1758720000000
}
```
**积木输出：**
- `最后收到的消息` → `{"x":5,"y":7,"player":"A"}`（若 `data` 为对象，自动转字符串）
- `最后收到的消息类型` → `move`

### 5. 接收命令
当收到合法 JSON 且 `type` 为 `"command"` 时，触发 `当收到命令 [COMMAND]` 积木。

**示例收到的数据：**
```json
{
  "type": "command",
  "command": "placePiece",
  "params": "5,7",
  "timestamp": 1758720000000
}
```
**积木输出：**
- `命令参数` → `5,7`
- `最后收到的消息类型` → `command`

### 6. 纯文本兜底
若收到的数据不是合法 JSON，扩展会自动包装为：
```json
{
  "type": "text",
  "data": "这是一段纯文本"
}
```
并触发 `当收到 [text] 文本消息时` 积木。
此时 `最后收到的消息` 返回原始字符串。

### 7. 连接与断开事件
这两个事件**不携带 JSON 数据**，仅由扩展内部触发：
- `当连接成功时`
- `当连接断开时`

### 8. 重连策略设置
`设置重连策略` 积木仅影响内部行为，不产生网络消息。

> **建议**：在自定义消息类型时，尽量使用有意义的英文单词（如 `boardSync`、`chat`、`heartbeat`），方便在积木下拉菜单中识别。
